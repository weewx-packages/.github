# WeeWX packages

Extensions, station drivers and skins for [WeeWX](https://weewx.com/).
Browse one catalog to find packages and their installation instructions.

[Browse the catalog](https://github.com/weewx-packages/catalog#readme) ·
[Compatibility checks](https://github.com/weewx-packages/catalog/actions/workflows/compatibility.yml) ·
[Upstream activity and backup status](https://github.com/weewx-packages/catalog/issues/1)

## What we do

We maintain a shared package catalog and preserve upstream projects through
regular source, issue, pull request and wiki backups. We mirror maintained
projects and continue selected abandoned projects in independent repositories.
Each project retains its license and credits.

Our compatibility checks install catalog releases and run project-specific
tests against WeeWX `master` and `development`. Hardware and live-service
requirements are documented per package.

## Start here

- [Package catalog](https://github.com/weewx-packages/catalog#readme): available packages, installation and updates.
- [Ecowitt HTTP Push](https://github.com/weewx-packages/weewx-ecowitt-http-push): receive uploads from Ecowitt gateways and consoles.
- [LiveData](https://github.com/weewx-packages/weewx-livedata): publish live weather readings through `live.php`.
- [Davis RTL-SDR](https://github.com/weewx-packages/weewx-rtldavis): receive Davis wireless observations with an RTL-SDR receiver.
- [Davis Cloud](https://github.com/weewx-packages/weewx-davis-cloud): a unified WeatherLink cloud driver, currently a prerelease.

## Help and contributions

Report package problems in the corresponding repository. For missing packages,
catalog errors or integration questions, [open a catalog issue](https://github.com/weewx-packages/catalog/issues/new).
Maintainers are welcome to contribute fixes and compatibility tests.

This is an independent community organization. For WeeWX itself, visit
[weewx/weewx](https://github.com/weewx/weewx).
